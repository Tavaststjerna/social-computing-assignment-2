# MiniSocial – Coding Assignment 2

Eeli Tavaststjerna – Social Computing 2026–2027, University of Oulu.

Added features: content moderation, user risk analysis and review before posting (Chapter 4, Design Claim 20). Developed with ChatGPT assistance.

## Run on Windows

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Open http://127.0.0.1:8080 in your browser.
